# Shaojun Shen | Selected work

[Open the portfolio](https://bulitofo.github.io/shaojun-selected-work/)

Three analysis pages examine college-town housing prices, FAA runway rankings, and London's hourly bike rentals. Each page includes a question, the relevant data, and an explanation of the limits. The photography section presents ten images from five of Shaojun Shen's original series, with local image files and links to the full series. The About page includes a professional contact address.

## Sources

- Housing data and the interactive report: [Campus Atlas](https://bulitofo.github.io/campus-atlas-market-report/).
- Runway characteristics: [FAA NASR](https://www.faa.gov/air_traffic/flight_info/aeronav/aero_data/NASR_Subscription/). The site reports two sample records and the cross-check from Shaojun’s analysis.
- Hourly rentals: [London bike sharing dataset](https://www.kaggle.com/datasets/hmavrodiev/london-bike-sharing-dataset). Counts are aggregated by holiday indicator and hour of day.
- Photography: © Shaojun Shen. [Original series](https://photos.shenshaojun.com/work).

Built with OpenAI ChatGPT Codex Desktop (GPT-6, local). GitHub Pages serves static HTML, CSS, and WebP files from the main branch.
